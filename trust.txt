#       写进 %LOCALAPPDATA%\PcCleanTool\my_trust.txt（优先级最高，不会被在线更新覆盖）
#       想把它贡献回在线库 → 启动项页点「我的库」复制，粘到本文件的末尾即可

#  格式：一行一条
#    keep|关键词|说明      命中就是"别关"（系统组件、驱动、安全软件、行业专用客户端）
#    bloat|关键词|说明     命中就是"建议关闭"（推广、捆绑、弹窗推手、常驻更新器）
#    同一行 keep 和 bloat 都命中时按 keep 算（防误伤）
#    关键词至少 3 个字符，太短的会被忽略（比如 hp 会误伤 php 这类路径）
