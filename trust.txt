#  这是"在线库"的格式样例，可以直接改内容用
# ------------------------------------------------------------
#  用法一（本地随包更新，不联网）
#    本文件改名叫  trust.txt，放到 电脑清理小工具.exe 同一个文件夹里，
#    打开软件 → 关于/联系 → 点「更新识别库」，立刻生效。
#    发给别人的时候顺手带上，别人装完也带着你这份库。
#
#  用法二（真正的在线更新）
#    把这个文件传到任一支持"直链访问"的地方（GitHub Gist 的 raw 链接、
#    阿里云 OSS、腾讯 COS、蓝奏云直链、自己的小服务器都行），
#    然后把地址填进 profile.txt：
#        trustUrl=https://你的地址/trust.txt
#    软件停用 7 天以上会自动在后台拉一次，也可以在「更新识别库」手动拉。
# ------------------------------------------------------------
#  格式：一行一条，三类写法都认
#    keep|关键词|说明      命中就是"别关"（系统组件、驱动、安全软件）
#    bloat|关键词|说明     命中就是"建议关闭"（推广、捆绑、弹窗推手）
#    关键词|说明           不带前缀的，默认当 keep
#  第一行的 ver= 会显示在软件界面上，改内容时顺手把日期改掉
# ============================================================
